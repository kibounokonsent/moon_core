# MOON CORE ARCHIVE — 未来世界 公式設定資料集

## フォルダ構成

```
moon_core/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── app.js                       ← 画面を生成する処理（通常は編集不要）
│   └── data/
│       ├── 00-categories.js          ← カテゴリー一覧／歴史年表／ARTICLES配列の宣言
│       ├── articles-world-life.js    ← 世界概要・人々の暮らし
│       ├── articles-tech.js          ← 科学技術
│       ├── articles-substance.js     ← 特殊物質
│       ├── articles-creature.js      ← 生物
│       ├── articles-mutant.js        ← 変異体
│       ├── articles-culture.js       ← 宗教・文化
│       ├── glossary.js               ← 用語集
│       ├── nations/                  ← ★国家は1国につき1ファイル（15ファイル）
│       └── org/                      ← ★組織・企業は1団体につき1ファイル（36ファイル）
└── assets/
    ├── mooncore.svg
    └── images/（カテゴリーごとの画像置き場。国旗は images/nation/flags/）
```

「国家」と「組織・企業」はファイル数が多く、今後も増え続けそうなので、
それぞれ**1項目＝1ファイル**に分割しました。新しい国・組織を追加するときは、
`js/data/nations/` または `js/data/org/` に新しいファイルを1つ作り、
`index.html` に `<script src="js/data/nations/新しいid.js"></script>` のような
1行を追加するだけです（既存のファイルをコピーして中身を書き換えるのが簡単です）。

それ以外のカテゴリー（世界概要・人々の暮らし・科学技術・特殊物質・生物・変異体・宗教文化）は
まだ数が少なく増減も緩やかなため、カテゴリーごとに1ファイルへまとめています。

  残して1つに統合しました（id は `kyuma` に統一）。

  `YYYY.MM.DD` 形式に統一しました。

  30件近く）も、対応する記事を特定できたものはすべて修正しています。

  そのまま残していますので、必要であれば内容をご確認ください。

  リンクするよう修正しました。

## 世界地図（インタラクティブ版）

- `js/world-map.js` と `css/world-map.css` で、世界地図ページの地図を描いています。
- 国境の形は `assets/world-map.svg` から取り出したもので、`js/world-map.js` の `WM_SHAPES` に入っています。
- 国をタップ → 右（スマホでは下）のパネルに概要。もう一度タップ、または「資料を開く」で国家記事へ。
- 新しい国を地図に足すときは、`WM_SHAPES` に `{ id:'記事のid', color:'#色', d:'SVGのパス' }` を、
  `WM_LABELS` に国名の位置を1行ずつ追加してください。パネルの「首都・人口」などは国家記事の info から自動で読みます。

## サウンド

- `js/sound.js` と `css/sound.css`。音声ファイルは使わず、ブラウザ内で音を合成しています。
- ヘッダーのスピーカーボタンで「効果音」「環境音」を別々にオン／オフ、音量も変えられます（設定はブラウザに保存）。
- 最初にどこかをタップ／クリックするまでは音が出ません（ブラウザの決まり）。
- 環境音は2層です。
  - 背景：どのページでも流れる明るいSFの和音（`startBase`）
  - 情景音：場所ごとに重なる音（`SCENE`）。割り当ては `NATION_SCENE`（国ごと）と `CAT_SCENE`（カテゴリーごと）。
    null にするとそのページは背景だけになります。
  - 使える情景音：forest（森）／sea（海）／ice（氷）／sky（空）／blizzard（吹雪）／mist（霧）／workshop（工房）／
    gears（歯車）／city（街）／music（遠くの音楽）／money（お金）／food（食）／data（情報）／crystal（結晶）／
    eerie（不気味）／life（暮らし）／history（鐘と紙）／culture（風鈴と鐘）／office（会社）／law（法廷）

## 今日の世界（部屋・トップ・記事の逆引き）

- `js/today.js` と `css/today.css`。データは既存の `CALENDAR_EVENTS`／`NEWS_ITEMS`／`CLIMATE_DATA`／国家記事だけを使います（新しく書くデータはありません）。
- **トップ「今日の世界」**：今日の行事（なければ「次の行事」）と最新ニュース3件。
- **部屋** `#/room`（`#/room/国家id` で国を指定）：
  - 窓＝その国の空模様。見ている人の時計で 夜明け→朝→昼→夕方→夜 と変わり、1分ごとに更新。
    天気は `CLIMATE_DATA` の月ごとの気温・降水量から「日付ごとに決まった値」を作るので、同じ日なら誰が見ても同じです。
  - 壁のカレンダー＝その国＋全世界の今日の行事。机の端末＝その国のニュース。本棚＝今日の一冊（まだ読んでいない記事を優先）。
  - 下に「世界の空模様」（全国家）。押すとその国の部屋へ。最後に選んだ国はブラウザに保存されます。
  - 窓の景色の種類は `today.js` の `ROOM_VIEW` に国ごと1行。新しい国はここに1行足してください（書かない国は平野）。
  - 部屋の内装は `today.js` の `ROOM_STYLE` に国ごと1行（壁・床・窓の形・カーテン・明かり・時計・カレンダー・端末・机・部屋の右側の家具・小物・夜に窓から入る光の色）。
    未来世界の人はほとんど本を読まないので、本棚は置いていません。部屋の右側は、その国の暮らしがいちばん出る家具の場所です。
    例：ニポラン＝床の間と龍の掛け軸／ヒューバート＝キャットタワーと猫たち／ガルヒューラ＝干し肉の竿だけの冷たい部屋（端末は NO SIGNAL）／
    マイモック＝乱れたベッドと散らかった床、漂う煙、動き続ける掃除ロボット（時計なし）／ラリアフルス＝植物と薬草、ヒカリタケ／タスメニオ＝透明な送水パイプ。
  - ユーレツェアは時計塔ツェンタル・ネヘタのある首都ミレタッツァ（文字盤は見ている人の時刻）、ヲンヘードは百層屋台街のある首都イーテスタを窓に描いています。
  - ヒューバート＝壁を渡る猫の通り道・猫トンネル・足場の猫／ユーレツェア＝工具の壁と部品棚、名前札の付いた道具、修理中の機械／
    ヲンヘード＝食卓と椅子、吊り灯り、台所の瓶と吊るした食材、「共に暖かく」の札。
  - サンルド＝首都ラルウォット（左に黄金のヴォルグレン、右に白金のクレディア、中央に中央均衡銀行）を窓に、部屋は黄金と白金の二色の壁、黒いビロードのカーテン、
    役割の仮面の陳列ケース、市場の流れの表示、チップと札。オルガロン＝首都フォルネータ（バルベルクの塔・大劇場・壁画・運河）を窓に、部屋はインクの飛び散り、
    ピアノ・チェロ・トランペット・バイオリン、描きかけのキャンバス。チリルド・アイルツア＝氷の街の窓と、大きな毛の塊のような雪犬。
    ラリアフルスは夜の月脈樹の参考画像に合わせ、大きな月と、霧の丘の向こうで光る樹冠、根元の街の灯を描いています。
  - 窓の景色は全15カ国とも `TD_VIEWS` の関数で描いています。共通の道具 `tdLS()`（遠いほど空の色に溶かす depth、なめらかな稜線 ridge、建物 building、もや mist、光のにじみ glow など）を使い、
    遠景→中景→近景を4〜6層で重ねる、見せ場は1つ、という決まりで構図を作っています。
    建物の列を描いたら、必ず `ground()` でその下を画面の下まで街並みで埋めてください（埋めないと街が宙に浮いて見えます）。
    街を見下ろす景色は `cityRows()` で、地平線から窓の下まで手前ほど大きな建物の段を重ねます。見せ場（塔・銀行など）は途中の段のあとに描くと、手前の建物で根元が隠れて自然に収まります。
    動くもの：`birds()`（鳥の群れ・昼だけ）、`plane()`（飛行機・昼は飛行機雲、夜は点滅灯）、`road()`（段のあいだの道路と車・夜はライト）、`forest()`（もりもりした森）。
    ガルヒューラ（交通なし）とマイモック（交通崩壊）には車や飛行機を走らせていません。フーモラ・スカイピルは空路に個人移動ポッド・中型飛行艇・公共空路輸送機が行き交います。
  - 参考画像のある8カ国（ニポラン・フーモラ・スカイピル・タスメニオ・ラリアフルス・ヒューバート・セルトシティ・ガルヒューラ・マイモック）は、
    窓の景色を `TD_VIEWS` の関数で個別に描いています（ラリアフルスは月脈樹、ニポランは格子の塔と光るドームなど）。ほかの国は `ROOM_VIEW` の景色です。
- **記事の逆引き**：記事ページの関連項目の上に「この国の行事とニュース」を表示（国家記事は `countries` の国名、
  それ以外は行事の `articleId` とニュースの `relatedArticleIds` で判定）。
- **世界カレンダー**（`js/calendar.js`・`css/calendar.css`）：記事ページと同じ見出し部品を使い、12か月の帯（行事の多さのバー付き）、
  国の色の付いた絞り込み、今日のマス、日付ごとの行事一覧、国の色の帯が付いたモーダルに作り直しました。開いたときは今月を表示します。
  `calendar-events.js` には歴史年表・国家記事にある出来事と文化から作った記念日を41件追加しています（2026.10 追加の見出しの下）。
- **ヘッダー**：「部屋」ボタンと「⋯」メニュー（部屋／世界カレンダー／世界ニュース／世界地図／企業適性診断／テーマ切替／サウンド設定）。
